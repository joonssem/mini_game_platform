# 운영 환경

교사 인터뷰로 확인한 내용 (2026-10-07). 코드에서 확인한 이전 프로젝트 정보는 `private/reference/`(git 제외)에 따로 둔다.

## 계정

| 항목 | 내용 |
|---|---|
| Convex | 무료 플랜. 이전 수업 활동과 같은 계정에 새 프로젝트 `mini-game-platform`을 만듦. 개발 배포 지역: **ap-southeast-2 (호주 시드니)** — 국외 처리 확인 시 참고 |
| Vercel | 개인 Hobby (무료) |
| GitHub ↔ Vercel | 같은 GitHub 계정으로 연결됨. 새 저장소를 바로 Import할 수 있다 |

## 학교 기기와 네트워크

| 항목 | 내용 | 설계에 주는 의미 |
|---|---|---|
| iPadOS | 18 이상 | 최신 Safari 기능(Pointer Events 등)을 별도 대체 코드 없이 쓸 수 있다 |
| 관리 제한(MDM) | 특별한 제한을 느낀 적 없음 | `*.vercel.app` 주소를 그대로 쓸 수 있다 |
| 학교 Wi-Fi + Convex 실시간 | 이전 활동에서 한 반 전체(20~30명)가 동시에 접속했고 바로바로 반영됨 | 이 게임의 동시 접속(방 몇 개 × 4명)은 그보다 훨씬 적다. T1 학교망 위험은 사실상 확인됨 |
| Firebase와 Convex | 활동에 따라 둘 다 사용. 비슷하거나 용도가 다름 | 이 프로젝트는 Convex로 확정 (DECISIONS.md) |
